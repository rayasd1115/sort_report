1. 氣泡排序法 (Bubble Sort)

原理

透過重複走訪陣列，比較相鄰的兩個元素，若順序錯誤則交換。每一輪走訪後，最大的元素會像「氣泡」一樣浮動到陣列末端。

複雜度分析

  • 時間複雜度：最佳 $O(n)$ / 平均 $O(n^2)$ / 最差 $O(n^2)$
  • 空間複雜度：$O(1)$

模擬實作內容

利用雙重迴圈控制，當 data[j] > data[j+1] 時執行交換。在模擬頁面中，會即時高亮顯示正在比較的相鄰色塊。

2. 選擇排序法 (Selection Sort)

原理

每一輪從「未排序部分」找出最小的元素，將其與未排序部分的第 1 個元素交換，直到所有元素都放入已排序部分。

複雜度分析

  • 時間複雜度：最佳 $O(n^2)$ / 平均 $O(n^2)$ / 最差 $O(n^2)$
  • 空間複雜度：$O(1)$

模擬實作內容

設定一個變數紀錄當前最小值的索引（index），掃描後方剩餘元素，最後僅執行一次交換動作。

3. 插入排序法 (Insertion Sort)

原理

逐一將未排序的元素取出，由後往前與已排序部分的元素比較，並插入到適當的位置（類似整理撲克牌）。

複雜度分析

  • 時間複雜度：最佳 $O(n)$ / 平均 $O(n^2)$ / 最差 $O(n^2)$
  • 空間複雜度：$O(1)$

模擬實作內容

實作上將選中的元素與左側已排序的元素依序比較，若左側較大則向右位移，直到找到插入點。

4. 合併排序法 (Merge Sort)

原理

採用分治法（Divide and Conquer），將陣列遞迴拆解至最小單位後，再依大小順序兩兩合併回原本的陣列。

複雜度分析

  • 時間複雜度：最佳 $O(n \log n)$ / 平均 $O(n \log n)$ / 最差 $O(n \log n)$
  • 空間複雜度：$O(n)$

模擬實作內容

透過遞迴函數處理拆解，並使用暫存陣列來存放合併過程中的排序結果，視覺化上呈現區塊式的合併。
