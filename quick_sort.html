快速排序是什麼？

快速排序是一種經典的分而治之演算法。每一輪先選一個樞紐值（pivot）， 把比 pivot 小的放左邊、比 pivot 大的放右邊，再遞迴處理左右子陣列。 平均情況下，時間複雜度是 O(n log n)。

Overview

先分區，再讓 pivot 就位

Quick Sort 的重點不是一路交換到底，而是每輪先完成一次分區。

1. 選擇 pivot

可用最後一個元素當 pivot，也可用隨機或三數取中降低最壞情況機率。

2. 分區

把小於等於 pivot 的值移往左邊，最後把 pivot 放到中間正確位置。

3. 左右遞迴

pivot 固定後，左右兩側區間再各自做同樣流程。

4. 得到完整排序

當每個區間長度都小於等於 1，陣列自然完成排序。

How It Works

快速排序的運作流程

每一輪先讓 pivot 就位，再把問題切成左右兩個更小的子問題。

選定 pivot

在目前區間挑一個元素當 pivot，常見寫法會用區間最後一個值。

掃描並分區

由左到右掃描，把小於等於 pivot 的值移到左側區塊。

pivot 就位

掃描結束後把 pivot 交換到中間，讓它位於最終正確位置。

遞迴左右子陣列

對 pivot 左右兩邊重複同樣流程，直到區間長度小於等於 1。

Implementation

C 語言實作

以下採用 Lomuto partition，示範 Quick Sort 典型寫法。

#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int partition(int arr[], int low, int high) {
    int pivot = arr[high];
    int i = low;

    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            swap(&arr[i], &arr[j]);
            i++;
        }
    }

    swap(&arr[i], &arr[high]);
    return i;
}

void quickSort(int arr[], int low, int high) {
    if (low >= high) {
        return;
    }

    int pivotIndex = partition(arr, low, high);
    quickSort(arr, low, pivotIndex - 1);
    quickSort(arr, pivotIndex + 1, high);
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int arr[] = {38, 27, 43, 3, 9, 82, 10};
    int n = sizeof(arr) / sizeof(arr[0]);

    printf("排序前: ");
    printArray(arr, n);

    quickSort(arr, 0, n - 1);

    printf("排序後: ");
    printArray(arr, n);

    return 0;
}

閱讀重點

  1. partition 會回傳 pivot 的最終位置。
  2. quickSort 再對 pivot 左右兩邊遞迴。
  3. 這個版本可原地排序，不需要額外合併陣列。

Comparison

優缺點與其他排序比較

快速排序常見且高效，但是否適合仍要看資料特性與穩定性需求。

優點

  • 平均時間複雜度為 O(n log n)，實務上速度通常很好。
  • 可原地排序，額外記憶體需求相對低。
  • 分區流程清楚，適合練習分治與遞迴思維。

缺點

  • 最壞情況會退化為 O(n²)。
  • 屬於不穩定排序，不保證相同值的相對順序。
  • 效能表現高度依賴 pivot 選擇策略。

When To Use

什麼情況適合使用快速排序？

Quick Sort 在一般排序任務很常見，但也要注意它的最壞情況與穩定性。

適合

  • 想要平均效能良好的通用排序方案。
  • 希望原地排序，降低額外記憶體開銷。
  • 想練習分區（partition）與遞迴分治思維。

不適合

  • 必須保證穩定排序（相同值順序不能改變）。
  • 需要避免最壞情況退化到 O(n²) 的風險。
  • 輸入資料特性容易讓 pivot 長期不平衡且未做優化時。

Takeaway

重點總結

快速排序的核心是「分區」，不是單純重複交換。

你應該記住的事

  • 每輪先讓 pivot 就位，再遞迴處理左右子陣列。
  • 平均時間複雜度是 O(n log n)，實務上常有優秀表現。

實際定位

  • 常見且高效的通用排序策略之一。
  • 需搭配良好的 pivot 策略，降低最壞情況風險。
