氣泡排序是什麼？

氣泡排序是一種最經典、也最容易理解的排序演算法。它會從頭到尾反覆比較相鄰的兩個元素， 只要順序錯了就交換位置，讓較大的值一輪一輪往後移動，像氣泡慢慢浮到水面一樣。

排序概念總覽 演算法流程解析 C 語言程式碼實作 互動排序示範 時間與空間複雜度 與其他排序比較 實務適用情境 重點與學習整理
核心策略 相鄰比較 + 逐輪交換
平均時間複雜度 O(n²)
排序特性 穩定、原地排序

Overview

先用一句話理解它

如果你剛接觸排序，氣泡排序幾乎是理解「比較」與「交換」概念的最佳入口。

核心想法

每一輪都把尚未排好的區間掃過一次，較大的元素會被逐步推到右側，因此每跑完一輪，陣列尾端就會多一個已經就定位的元素。

名稱由來

因為較大或較小的元素會透過不斷交換慢慢移動，視覺上很像氣泡在水中往上浮動，所以稱為 Bubble Sort。

它適合學什麼

透過它可以學會巢狀迴圈、交換操作、最佳化停止條件，以及時間複雜度為什麼會從線性成長到平方級。

現實中的定位

它很少用在大型正式系統裡，但在教學、面試基礎題、小型資料集與近乎排序完成的資料上仍然很有價值。

How It Works

氣泡排序的運作流程

把它想成不斷重複的四個小步驟，理解後幾乎就能自己寫出程式。

從左到右掃描

從陣列第一個元素開始，依序比較每一對相鄰元素，例如比較第 1 與第 2 個、第 2 與第 3 個，直到最後。

順序錯了就交換

如果前面的值比後面的值大，就把它們交換位置。這個動作會讓較大的元素慢慢往右移動。

每輪固定一個位置

第一輪結束後，最大值一定會移到最右邊；第二輪後，次大值也會到倒數第二格，以此類推。

沒有交換就提早結束

若某一輪完全沒有發生交換，代表資料已排序完成。這個小優化能讓最佳情況下降到 O(n)。

Implementation

C 語言實作

這個版本用 C 語言示範氣泡排序，包含提前停止的優化，也保留最典型的陣列交換寫法。

#include <stdio.h>

void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;

        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = 1;
            }
        }

        if (!swapped) {
            break;
        }
    }
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int arr[] = {64, 34, 25, 12, 22, 11, 90};
    int n = sizeof(arr) / sizeof(arr[0]);

    printf("排序前: ");
    printArray(arr, n);

    bubbleSort(arr, n);

    printf("排序後: ");
    printArray(arr, n);

    return 0;
}

閱讀這段程式時，請先看三個重點

  1. 外層迴圈代表「第幾輪」，每一輪都會固定一個最終位置。
  2. 在 C 語言中，函式通常要另外接收陣列長度，所以會傳入 arr 與 n。
  3. temp 與 swapped 很重要，前者負責交換資料，後者負責提早結束排序。

Complexity

時間與空間複雜度分析

它的優點是簡單，但代價也很明顯：當資料量變大時，效率會快速下降。

最佳情況

資料原本就有序，只需一輪掃描。

O(n)

平均情況

通常需要大量比較與部分交換。

O(n²)

最壞情況

資料完全反序，交換次數最多。

O(n²)

空間複雜度

只需少量暫存變數，屬於原地排序。

O(1)

為什麼會是 O(n²)

因為第一輪大約比較 n-1 次、第二輪比較 n-2 次，直到最後一輪比較 1 次，所以總比較次數是等差級數相加。

(n - 1) + (n - 2) + ... + 1 = n(n - 1) / 2

為什麼最佳情況是 O(n)

如果第一輪檢查完發現完全沒有交換，就代表資料原本已排序。此時直接停止，不需要再做後續輪次。

Comparison

優缺點與其他排序比較

氣泡排序的重點不是「最快」，而是「最直觀」。把它放進排序家族裡看會更清楚。

優點

  • 概念簡單，初學者容易理解與手寫。
  • 不需要額外陣列，屬於原地排序。
  • 是穩定排序，相同值的相對順序會保留。
  • 對幾乎排序完成的小型資料集仍可接受。

缺點

  • 資料量一大，時間複雜度 O(n²) 會很明顯。
  • 交換次數偏多，實務上效率通常不理想。
  • 正式專案多半會選擇更高效的排序方法。
  • 主要價值更偏向教學與理解基礎概念。

When To Use

什麼情況適合使用氣泡排序？

判斷是否使用，不是看它有沒有名氣，而是看資料規模、可讀性需求，以及你是否正在學習。

適合

  • 資料量非常小，程式簡單比極致效能更重要。
  • 用來教學、報告、簡報或展示排序原理。
  • 資料幾乎已排序，且有提前停止機制。
  • 需要穩定排序，但規模不大。

不適合

  • 大型資料集或需要高效能處理的正式系統。
  • 排序會被頻繁呼叫、效能是關鍵瓶頸的場景。
  • 已有更成熟內建排序可使用的應用程式。
  • 需要可擴充處理大量資料的後端流程。

Takeaway

重點總結

如果你只想記住最重要的事，記住下面這三句就夠了。

你應該記住的事

  • 氣泡排序透過反覆比較相鄰元素並交換位置，逐輪把最大值推到右端。
  • 它的優勢是直觀、穩定、原地排序；劣勢是平均與最壞情況效率都只有 O(n²)。

實際定位

它最適合用在教學、小型資料集或幾乎排序完成的情況，而不是大量正式資料處理。
