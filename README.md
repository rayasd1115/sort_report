## 氣泡排序法

### 原理簡述
透過相鄰元素兩兩比較，若順序錯誤就交換，讓較大元素逐步「冒泡」到序列尾端。每輪可固定一個最大值位置。

### 複雜度分析
- 時間複雜度：最佳 $O(n)$（已排序且有提早結束機制）、平均 $O(n^2)$、最差 $O(n^2)$
- 空間複雜度：$O(1)$

### 模擬實作內容
- 以逐步比較高亮顯示目前比較中的兩個元素
- 發生交換時即時更新陣列視覺位置
- 每回合完成後標記已確定位置的尾端元素

## 選擇排序法

### 原理簡述
每一輪從未排序區間中找出最小值，與該輪起始位置交換，逐步擴大已排序區間。

### 複雜度分析
- 時間複雜度：最佳/平均/最差皆為 $O(n^2)$
- 空間複雜度：$O(1)$

### 模擬實作內容
- 以顏色區分「目前最小值」與「掃描指標」
- 一輪掃描結束後執行一次交換並更新畫面
- 顯示已排序前綴區間的成長過程

## 插入排序法

### 原理簡述
將序列視為已排序與未排序兩部分，每次取未排序區間第一個元素插入到已排序區間的正確位置。

### 複雜度分析
- 時間複雜度：最佳 $O(n)$、平均 $O(n^2)$、最差 $O(n^2)$
- 空間複雜度：$O(1)$

### 模擬實作內容
- 顯示當前待插入元素（key）
- 視覺化元素右移過程，直到找到插入點
- 每次插入後更新已排序區間邊界

## 合併排序法

### 原理簡述
採用分治法，先遞迴將陣列分成更小子陣列，子陣列排序後再兩兩合併，最終得到整體有序結果。

### 複雜度分析
- 時間複雜度：最佳/平均/最差皆為 $O(n \log n)$
- 空間複雜度：$O(n)$

### 模擬實作內容
- 顯示遞迴切分層次與子陣列範圍
- 合併階段逐步比較左右子陣列元素
- 完成一次 merge 後即時回寫並刷新畫面

## 快速排序法

### 原理簡述
選定一個 pivot，將序列重排為「小於 pivot」與「大於等於 pivot」兩側，再遞迴處理左右子序列。

### 複雜度分析
- 時間複雜度：最佳/平均 $O(n \log n)$、最差 $O(n^2)$
- 空間複雜度：平均 $O(\log n)$（遞迴堆疊）、最差 $O(n)$

### 模擬實作內容
- 以不同顏色標示 pivot、左指標、右指標
- 分割（partition）過程即時呈現交換與指標移動
- 每次 partition 完成後標示 pivot 最終位置

## 綜合比較

1. 小型或接近有序資料：插入排序法表現通常較佳，實作簡單且常數成本低。  
2. 需要穩定且可預期的效能：合併排序法在各情況皆為 $O(n \log n)$，但需要額外記憶體。  
3. 一般情境追求平均效能：快速排序法常有不錯實務表現，但需注意最差情況。  
4. 教學與基礎理解：氣泡與選擇排序法流程直觀，適合入門比較排序概念。

## 學習心得

透過本次排序模擬實作，我更清楚理解不同排序法在「比較次數、交換次數、記憶體使用」上的差異。雖然基礎排序（如氣泡、選擇、插入）在大資料量時效率較低，但非常適合建立演算法思維；而分治法（合併、快速）則展現了更好的擴充性。實作動畫過程也讓抽象流程具體化，幫助我能更直觀的理解整個排序邏輯。
