合併排序是什麼？

合併排序是一種經典的分而治之排序法。你可以先把它和氣泡排序一起看：Bubble Sort 是反覆比較與交換，Merge Sort 則是先拆分、再合併。 這種做法讓它在資料量變大時，仍能維持穩定的 O(n log n) 效能。

Overview

先切小，再合併回來

如果你已經看過氣泡排序，這裡的重點就是換一種思考方式，不再靠反覆交換，而是用拆分與合併完成排序。

1. 把大問題切成小問題

Merge Sort 會先把陣列切成左右兩半，直到每段都只剩 1 個元素。

2. 小段資料天然已排序

單一元素本身就符合排序狀態，這會成為後面合併的基礎。

3. 合併時只看最前面

當左右兩段都排好之後，只要比較兩邊最前面的元素，就能決定下一個放誰。

4. 最後回到完整陣列

每次合併都會產生更大的已排序區間，直到整個陣列重新拼回來。

How It Works

合併排序的運作流程

把它想成先把一疊牌拆開，再把排好的牌一張一張合回去。

先切成左右兩半

把原始陣列切成左右兩半，這個動作會一直重複到每一段只剩一個元素。

左右子陣列各自排序

左右兩邊會再繼續拆分，讓每一小段都先變成「已排序」狀態。

用雙指標做合併

兩段已排序資料會從最前面開始比較，較小的值先放入結果陣列。

把結果一層層回推

每合併一層，就得到更大的已排序區間，最後回到完整陣列。

Implementation

C 語言實作

這個版本用 C 語言示範 Merge Sort，重點在於 merge 函式如何把兩段已排序資料接回去。

#include <stdio.h>

void merge(int arr[], int temp[], int left, int mid, int right) {
    int i = left;
    int j = mid + 1;
    int k = left;

    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
        }
    }

    while (i <= mid) {
        temp[k++] = arr[i++];
    }

    while (j <= right) {
        temp[k++] = arr[j++];
    }

    for (i = left; i <= right; i++) {
        arr[i] = temp[i];
    }
}

void mergeSort(int arr[], int temp[], int left, int right) {
    if (left >= right) {
        return;
    }

    int mid = left + (right - left) / 2;
    mergeSort(arr, temp, left, mid);
    mergeSort(arr, temp, mid + 1, right);
    merge(arr, temp, left, mid, right);
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int arr[] = {38, 27, 43, 3, 9, 82, 10};
    int n = sizeof(arr) / sizeof(arr[0]);
    int temp[n];

    printf("排序前: ");
    printArray(arr, n);

    mergeSort(arr, temp, 0, n - 1);

    printf("排序後: ");
    printArray(arr, n);

    return 0;
}

閱讀這段程式時，先看三個重點

  1. mergeSort 會持續把區間拆半，直到 left 和 right 重疊。
  2. merge 函式負責把兩段已排序資料重新整理成一段完整結果。
  3. temp 陣列用來暫存合併結果，再一次寫回原陣列。

Complexity

時間與空間複雜度分析

合併排序的優勢是速度穩定，但代價是需要額外的暫存空間。

最佳情況

即使資料已接近排序，仍然需要完成拆分與合併流程。

O(n log n)

平均情況

效能非常穩定，這也是它常被當作高效率排序範例的原因。

O(n log n)

最壞情況

因為流程固定，最壞情況也不會退化成平方級。

O(n log n)

額外空間

需要額外暫存陣列來完成合併，這是 Merge Sort 的主要代價。

Comparison

優缺點與其他排序比較

如果你要記住 Merge Sort 的定位，最重要的是：它比 Bubble Sort 更快，但需要更多空間。

優點

  • 時間複雜度穩定，平均、最好與最壞情況都很一致。
  • 屬於穩定排序，相同值的相對順序可以保留。
  • 適合中大型資料集，比 Bubble Sort 更有實務價值。
  • 分而治之的寫法很適合學習遞迴思維。

缺點

  • 需要額外的 O(n) 暫存空間。
  • 遞迴與合併邏輯比 Bubble Sort 更長，初學者要花更多時間理解。
  • 對非常小的資料集，不一定比簡單排序法更划算。
  • 如果只是學最基礎的交換與比較，Bubble Sort 更直觀。

When To Use

什麼情況適合使用合併排序？

它很適合需要穩定效能的場景，尤其是資料量越大時越能看出優勢。

適合

  • 資料量較大，想要穩定的 O(n log n) 效能。
  • 需要穩定排序，保留相同值的相對順序。
  • 想學習分而治之與遞迴的典型範例。

不適合

  • 非常小的資料集，且你更在意程式簡短。
  • 記憶體資源很緊張，無法接受 O(n) 額外空間。
  • 只需要最簡單、最直觀的排序流程。

Takeaway

重點總結

Merge Sort 的核心不是交換，而是先拆開再合回來。

你應該記住的事

  • 拆分到最小單位後，再用合併把資料重新整理成有序陣列。
  • 效能穩定，但要付出額外記憶體成本。

實際定位

  • 適合中大型資料與需要穩定排序的場景。
  • 也是理解遞迴與分而治之時非常經典的範例。
