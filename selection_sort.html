選擇排序是什麼？

選擇排序的核心想法是「每一輪都找最小值」，然後放到前面該在的位置。 它的交換次數通常比氣泡排序少，流程也很規律，適合拿來理解「搜尋最值 + 固定位置」這種排序策略。

直接看排序示範 比較氣泡排序
最佳 / 平均 / 最壞時間 O(n²)
空間複雜度 O(1)
關鍵特性 原地排序、通常不穩定
學習重點 最小值搜尋與區間縮小

Overview

一句話掌握選擇排序

每一輪從未排序區間找出最小值，放到區間最前面，已排序區間就會持續向右擴大。

核心想法

把陣列切成「已排序」和「未排序」兩區，每輪都在未排序區間找到最小值，並與區間起點交換。

它的節奏

第 1 輪固定第 1 個位置、第 2 輪固定第 2 個位置，直到倒數第 2 個位置固定後就完成排序。

和氣泡排序差異

氣泡排序是靠相鄰交換慢慢推動，選擇排序是先找最小值再一次交換，交換次數通常更少。

實務定位

雖然時間複雜度仍是 O(n²)，但邏輯清楚、記憶體需求低，常用於教學或小規模資料處理。

How It Works

選擇排序運作流程

你可以把它想成重複執行四步：鎖定起點、找最小值、交換、縮小範圍。

鎖定本輪起點 i

從左到右進行，每一輪先把當前位置 i 當作候選最小值的位置。

掃描右側區間

從 i + 1 開始往後找，若找到更小元素，就更新最小值索引 minIndex。

與起點交換

掃描結束後，把 minIndex 和 i 交換，最小值就會固定在正確位置。

已排序區間擴大

每完成一輪，前綴區間 [0..i] 都已經排序好，接著處理下一個位置。

Implementation

C 語言實作

這份程式碼示範典型的選擇排序：雙層迴圈、最小值追蹤、結束時再交換一次。

#include <stdio.h>

void selectionSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;

        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }

        if (minIndex != i) {
            int temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int arr[] = {29, 10, 14, 37, 13};
    int n = sizeof(arr) / sizeof(arr[0]);

    printf("排序前: ");
    printArray(arr, n);

    selectionSort(arr, n);

    printf("排序後: ");
    printArray(arr, n);

    return 0;
}

讀程式時先看這三點

  1. 外層迴圈的 i 代表「這一輪要固定哪個位置」。
  2. minIndex 會隨著內層比較持續更新，最後停在最小值位置。
  3. 交換在每輪最後發生一次，所以交換次數上限是 n - 1。

Complexity

時間與空間複雜度分析

選擇排序的比較次數很固定，所以時間複雜度沒有因資料排列而明顯改善。

最佳 / 平均 / 最壞時間

不管資料原本有沒有排序，都要完成完整掃描，所以三種情況通常都是 O(n²)。

空間複雜度

只需要少量暫存變數來做交換，因此屬於原地排序，空間複雜度是 O(1)。

Comparison

優缺點與其他排序比較

先看選擇排序本身的優缺點，再把它放進 Bubble、Insertion 與 Merge Sort 的家族裡一起比較。

優點

  • 交換次數比氣泡排序少，最多只會發生 n - 1 次交換。
  • 程式邏輯固定，適合用來學習「固定位置」的排序思維。
  • 屬於原地排序，只需要很少額外空間。

缺點

  • 不管資料是否接近排序，都要完整掃描，時間複雜度仍是 O(n²)。
  • 通常不穩定，遇到相同值時相對順序可能改變。
  • 比起插入排序與 Merge Sort，實務效能通常不夠好。
演算法 最佳 平均 最壞 空間 穩定性
氣泡排序 O(n) O(n²) O(n²) O(1) 穩定
選擇排序 O(n²) O(n²) O(n²) O(1) 不穩定
插入排序 O(n) O(n²) O(n²) O(1) 穩定
合併排序 O(n log n) O(n log n) O(n log n) O(n) 穩定

選擇排序適合拿來理解「每輪找最小值」的策略，但如果要處理大資料，通常會改用插入排序或 Merge Sort。

When To Use

什麼情況適合使用選擇排序？

它不是最快的排序法，但在教學、簡單資料整理與交換成本高的情境仍有價值。

適合

資料量很小、你想要清楚理解排序流程、或者交換成本比比較成本更高的情境。

不適合

資料量大、需要高效率處理，或是已經有更成熟的內建排序可用時，就不太適合。

Takeaway

重點總結

選擇排序的核心，是每輪都把最小值放到正確位置，讓前綴區間逐步完成排序。

你應該記住的事

它的比較次數固定、交換次數較少、空間需求也很低，因此很適合拿來理解「固定位置」這種排序思維。

實際定位

對初學者來說，它是非常好的排序入門範例；但若要處理大量資料，通常會選擇更高效率的方法。
