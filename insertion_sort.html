插入排序是什麼？

插入排序的核心想法是把資料想成「左邊已排序、右邊未排序」。 每一輪拿出一個新元素，往左比較並插入正確位置，特別適合幾乎已經排好序的資料。

Overview

一句話掌握插入排序

每一輪都把下一個元素插進左側已排序區間，讓已排序範圍逐步擴大。

核心想法

把當前元素當作 key，從左側往回比，遇到比 key 大的元素就往右移，最後把 key 插入空出的位置。

它的節奏

第 1 輪讓前 2 個元素有序，第 2 輪讓前 3 個元素有序，直到整個前綴區間擴張到全陣列。

和氣泡排序差異

氣泡排序靠相鄰交換推動，插入排序則把元素直接插入定位，對近乎有序資料通常更有效率。

實務定位

平均仍是 O(n²)，但程式簡潔、空間 O(1)，常作為混合排序中的小區段優化策略。

How It Works

插入排序運作流程

你可以把它想成重複四步：取 key、向左比較、右移元素、插入 key。

選出本輪 key

從第 2 個元素開始，將 arr[i] 存成 key，準備插入左側已排序區間。

往左逐一比較

用 j = i - 1 往左掃描，只要 arr[j] 比 key 大，就把 arr[j] 右移到 arr[j + 1]。

找到插入點

當 j 越界或遇到 arr[j] <= key 時停止，這時 j + 1 就是 key 應該放的位置。

插入後擴大前綴

把 key 放進 arr[j + 1]，此時前綴 [0..i] 已排序，進入下一輪。

Implementation

C 語言實作

這份程式碼示範典型的插入排序：以 key 為核心，使用位移取代多次交換。

#include <stdio.h>

void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;

        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }

        arr[j + 1] = key;
    }
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int arr[] = {8, 4, 6, 3, 7};
    int n = sizeof(arr) / sizeof(arr[0]);

    printf("排序前: ");
    printArray(arr, n);

    insertionSort(arr, n);

    printf("排序後: ");
    printArray(arr, n);

    return 0;
}

讀程式時先看這三點

  1. 外層迴圈 i 代表「把第 i 個元素插進左側已排序區」。
  2. while 迴圈負責將比 key 大的元素向右位移，直到找到插入點。
  3. 最後把 key 放回 arr[j + 1]，就完成一輪插入。

Complexity

時間與空間複雜度分析

插入排序對近乎有序資料表現很好，但最壞情況仍然是平方級。

最佳情況

如果資料幾乎已排序，內層 while 幾乎不用位移，時間複雜度可以接近 O(n)。

平均 / 最壞情況

當資料亂序時，需要反覆位移元素，因此平均與最壞情況通常都是 O(n²)。

空間複雜度

只使用少量暫存變數 key 和 j，屬於原地排序，空間複雜度是 O(1)。

特性總結

插入排序穩定、程式簡潔，適合小型資料與近乎有序的資料處理。

Comparison

優缺點與其他排序比較

先看插入排序本身的優缺點，再把它放進 Bubble、Selection 與 Merge Sort 的家族裡一起比較。

優點

  • 對近乎有序的資料特別快，最佳情況可以接近 O(n)。
  • 屬於穩定排序，能保留相同值的相對順序。
  • 只需要很少額外空間，程式也容易理解。

缺點

  • 平均與最壞情況仍然是 O(n²)，資料越亂效能越差。
  • 需要反覆位移元素，當陣列很大時成本會增加。
  • 面對大型資料集時，通常不如 Merge Sort 或 Quick Sort 實用。

插入排序很適合和氣泡排序一起學，因為一個是「交換」，一個是「位移 + 插入」，差異會很清楚。

When To Use

什麼情況適合使用插入排序？

它特別適合小資料、近乎有序資料，或者需要維持穩定排序的情境。

適合

資料量小、資料幾乎已經排好、或是你想要一個容易理解又穩定的排序實作時。

不適合

如果資料量很大、而且排列通常很亂，插入排序的 O(n²) 成本就會開始變得不划算。

Takeaway

重點總結

插入排序的關鍵是「把元素插進正確位置」，而不是一直交換。

你應該記住的事

它透過位移來騰出空間，讓 key 插入到左側已排序區間中，因此對近乎有序資料很有效率。

實際定位

在教學與小資料場景中非常實用，也常被拿來和氣泡排序對照理解「交換」與「位移」的差異。
