🔄 氣泡排序（Bubble Sort）演算法分析

最佳時間 O(n)
平均時間 O(n²)
最壞時間 O(n²)
空間複雜度 O(1)

📖 演算法概述

氣泡排序是一種簡單的排序演算法，它重複地遍歷待排序的數列，一次比較兩個元素， 如果它們的順序錯誤就把它們交換過來。遍歷數列的工作重複進行，直到不需要再交換為止， 這表示數列已經排序完成。

這個演算法的名字由來是因為越小的元素會經由交換慢慢「浮」到數列的頂端， 就如同水中的氣泡一樣浮到水面。

💻 演算法實作（JavaScript）

function bubbleSort(arr) {
    const n = arr.length;
    
    // 外層迴圈：控制排序輪數
    for (let i = 0; i < n - 1; i++) {
        let swapped = false;
        
        // 內層迴圈：進行相鄰元素的比較與交換
        for (let j = 0; j < n - i - 1; j++) {
            // 如果前一個元素大於後一個元素，則交換
            if (arr[j] > arr[j + 1]) {
                // 交換元素
                [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
                swapped = true;
            }
        }
        
        // 如果這一輪沒有發生交換，表示已經排序完成
        if (!swapped) {
            break;
        }
    }
    
    return arr;
}

// 使用範例
const array = [64, 34, 25, 12, 22, 11, 90];
console.log("原始陣列：", array);
console.log("排序後：", bubbleSort([...array]));

📊 時間複雜度分析

1. 最佳情況（Best Case）

時間複雜度：O(n)

當輸入的陣列已經是有序的時候，只需要進行一次遍歷，比較 n-1 次，不需要進行任何交換。 使用 swapped 標記可以在第一輪結束後就停止演算法。

2. 平均情況（Average Case）

時間複雜度：O(n²)

在平均情況下，需要進行約 n²/4 次比較和約 n²/4 次交換。

3. 最壞情況（Worst Case）

時間複雜度：O(n²)

當輸入的陣列是完全逆序的時候，需要進行最多次數的比較和交換。

比較次數 = (n-1) + (n-2) + (n-3) + ... + 1 = n(n-1)/2 = O(n²)

詳細計算過程

對於長度為 n 的陣列：

  • 第 1 輪：需要比較 n-1 次
  • 第 2 輪：需要比較 n-2 次
  • 第 3 輪：需要比較 n-3 次
  • ...
  • 第 n-1 輪：需要比較 1 次

總比較次數 = (n-1) + (n-2) + ... + 1 = n(n-1)/2

💾 空間複雜度分析

空間複雜度：O(1)

氣泡排序是一種原地排序演算法，只需要常數額外空間來存儲臨時變量（用於交換元素）。 不需要額外的陣列或大量的記憶體空間。

🔍 演算法執行範例

以陣列 [5, 3, 8, 4, 2] 為例：

初始狀態： [5, 3, 8, 4, 2]
第 1 輪：
  比較 5 和 3：[3, 5, 8, 4, 2]（交換）
  比較 5 和 8：[3, 5, 8, 4, 2]（不交換）
  比較 8 和 4：[3, 5, 4, 8, 2]（交換）
  比較 8 和 2：[3, 5, 4, 2, 8]（交換）
  → 最大值 8 已就位
第 2 輪：
  比較 3 和 5：[3, 5, 4, 2, 8]（不交換）
  比較 5 和 4：[3, 4, 5, 2, 8]（交換）
  比較 5 和 2：[3, 4, 2, 5, 8]（交換）
  → 次大值 5 已就位
第 3 輪：
  比較 3 和 4：[3, 4, 2, 5, 8]（不交換）
  比較 4 和 2：[3, 2, 4, 5, 8]（交換）
  → 4 已就位
第 4 輪：
  比較 3 和 2：[2, 3, 4, 5, 8]（交換）
  → 3 已就位
最終結果： [2, 3, 4, 5, 8] ✓

✅ 優點

  • 實作簡單，容易理解
  • 不需要額外的記憶體空間（原地排序）
  • 是穩定的排序演算法（相同元素的相對位置不會改變）
  • 對於小型資料集或幾乎已排序的資料效率尚可

❌ 缺點

  • 時間複雜度較高，對大型資料集效率很差
  • 需要進行大量的元素交換操作
  • 實際應用中很少使用，主要用於教學目的

🎯 適用場景

氣泡排序適合用於：

  • 資料量很小的情況（n < 50）
  • 資料已經基本有序
  • 教學演示排序演算法的基本概念
  • 對穩定性有要求且資料量不大的情況

不建議用於：

  • 大型資料集的排序
  • 對效能有較高要求的生產環境

📝 總結

氣泡排序雖然實作簡單，但由於其 O(n²) 的時間複雜度，在實際應用中效率較低。 它主要的價值在於教學，幫助初學者理解排序演算法的基本概念和比較、交換的操作原理。 在實際專案中，應該選擇更高效的排序演算法，如快速排序或合併排序。

然而，對於非常小的資料集或已經幾乎排序好的資料，氣泡排序的效能可能與更複雜的演算法相當， 而其簡單性使得它在某些特定場景下仍有一定的實用價值。
